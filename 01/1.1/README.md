## Часть 1. Устройство компьютера

### 1. Характеристики процессора

Для получения информации о процессоре в Manjaro Linux выполнена команда:

```bash
lscpu
```

Результаты:

| Параметр | Значение |
|---|---|
| Модель процессора | AMD Ryzen 5 7600X 6-Core Processor |
| Архитектура | x86_64 |
| Физические ядра | 6 |
| Потоки на ядро | 2 |
| Логические процессоры | 12 |
| Базовая частота | 4,7 ГГц |
| L1d | 192 КиБ суммарно (6 × 32 КиБ) |
| L2 | 6 МиБ суммарно (6 × 1 МиБ) |
| L3 | 32 МиБ, общий кэш |

Полный вывод команды сохранён в файле [`lscpu.txt`](lscpu.txt). Базовая частота уточнена по [спецификации AMD Ryzen 5 7600X](https://www.amd.com/en/products/processors/desktops/ryzen/7000-series/amd-ryzen-5-7600x.html), так как `lscpu` показывает минимальную и максимальную частоты, но не базовую.

### 2. Информация о процессоре средствами Python

В интерпретаторе Python выполнены команды из задания:

```python
import os, platform
print(platform.machine())
print(os.cpu_count())
```

Результат:

```text
x86_64
12
```

`platform.machine()` возвращает архитектуру процессора, а `os.cpu_count()` — число логических процессоров. Результат соответствует выводу `lscpu`: 6 физических ядер × 2 потока = 12 логических процессоров.

### 3. Объяснение понятий

**Зачем процессору кэш?** Кэш — быстрая память рядом с ядром, которая позволяет получать часто используемые данные и инструкции с меньшей задержкой, чем из оперативной памяти. L1 обычно самый быстрый и небольшой, L2 больше, а L3 ещё больше и может использоваться несколькими ядрами.

**Почему ядер несколько?** Несколько физических ядер позволяют одновременно выполнять разные задачи или независимые части одной вычислительной задачи. При этом ускорение зависит от того, можно ли распараллелить программу.

**Что такое такт?** Такт — один период тактового сигнала процессора. Частота 4,7 ГГц означает примерно 4,7 миллиарда тактов в секунду. За один такт ядро может выполнять несколько операций, поэтому один такт не равен одной инструкции или одной арифметической операции.

### 4. Оценка теоретического пика одного ядра в GFLOPS

В выводе `lscpu` обнаружены флаги `avx2`, `avx512f` и `fma`. Следовательно, процессор поддерживает AVX2, AVX-512 и операции FMA.

По формуле из задания:

$$
P = f \cdot 2 \cdot N_{FMA} \cdot W
$$

Для оценки при работе с числами одинарной точности (`float32`) и AVX2 приняты параметры:

- $f = 4{,}7$ ГГц — базовая частота;
- $2$ — две операции с плавающей точкой на элемент при FMA (умножение и сложение);
- $N_{FMA} = 2$ — две 256-битные FMA-операции за такт на ядро;
- $W = 8$ — восемь 32-битных чисел в 256-битном векторе AVX2.

$$
P = 4{,}7 \cdot 2 \cdot 2 \cdot 8 = 150{,}4\ \text{GFLOPS}
$$

**Итог:** оценка теоретической пиковой производительности одного ядра AMD Ryzen 5 7600X составляет **150,4 GFLOPS** для `float32` при базовой частоте 4,7 ГГц и использовании AVX2/FMA. Это расчётный максимум, а не измеренный результат программы.
